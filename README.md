# clj-soroban-practice

This is a small app for Soroban practice.

The goal was to learn a bit more of ClojureScript using Replicant and Nexus, and this project seemed like a nice fit.

## Pre-requisites

- Java JDK
- Clojure CLI (tested on 1.12.4)
- npm (tested on 10.8.2)
- node (tested on v20.19.5)

## How to run

```
npm install
npx shadow-cljs watch app
```
