# Planning

The digital soroban is not very practical, so we should encourage the user to practice on a real one. 

Add visualization mode:

- User types a number in the input box and the app displays the representation in the soroban.
- User clicks in the soroban to change the number.

Add practice modes for digital/real soroban:

- User clicks a "Practice Numbers" button, receives a number, user puts the number in the soroban, user clicks on another button to show and check the answer.
- User clicks a "Practice Operations" button, customizes some options, user receives a series of numbers to add/subtract, user puts the result in the soroban, user clicks on another button to show and check the answer.
